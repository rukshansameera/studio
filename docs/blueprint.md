# **App Name**: StudentHub

## Core Features:

- Google SSO Login: Authenticate users using Google Single Sign-On (SSO).
- Student Profile Display: Display student profile information including name, and age.

## Style Guidelines:

- Primary color: Light sky blue (#87CEEB) evoking a sense of calm and intelligence.
- Background color: Off-white (#F5F5F5) providing a clean and modern look.
- Accent color: Soft orange (#FFB347) to highlight interactive elements.
- Body and headline font: 'Inter' for a modern, clean, and readable interface.
